# Experiment 5 - Web Automation

**Run:** Open `project.json` and click **Run**. It opens your default browser to a search URL and writes `Output/browser_automation_demo.txt`.

**Native UiPath activity chain for your practical:** `Use Application/Browser` -> `Type Into` the search box -> `Click` the search button -> `Get Text` from the visible result -> `Log Message` -> close browser. Use UiExplorer/selector editor and suitable wait/check activities if required.

**Important distinction:** The one-click demo opens a search URL; it does not pre-record browser selectors because selectors depend on your browser and site layout. Capture them on your own Windows computer. Page 17 of your record shows the website search and captured result.
